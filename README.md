# Milo — مدیر پروژه

اپِ تحت‌وبِ مستقل برای تعریفِ پروژه، طراحیِ ساختارِ درختیِ آن (کلیات ← زیرمجموعه ← جزئیات)، وابستگی‌ها، ورودی/خروجیِ
ماژول‌ها، زمان‌بندی/تایم‌لاین و گرفتن/برگرداندنِ فایلِ پروژه برای هوش مصنوعی. پروژهٔ مستقل است.

## نصب روی cPanel

۱. محتوای این مخزن را (کامل) روی هاست بگذارید؛ مثلاً در `public_html/pm` ← نشانی `https://دامنه/pm/`.
۲. نیازمندی: PHP ۸٫۰+ با `pdo_sqlite` (در cPanel پیش‌فرض فعال است؛ در «Select PHP Version» هم می‌شود دید) و برای دانلودِ
   zip پیوست‌ها `zip`.
۳. اولین بار که صفحه را باز کنید، نام‌کاربری و رمز می‌سازید (همان حسابِ مدیر). تمام.

نکات:

- دادهٔ برنامه در `data/pm.sqlite` و پیوست‌ها در `data/uploads/` است. پوشهٔ `data` با `.htaccess` از بیرون بسته است؛
  **از همین پوشه پشتیبان بگیرید.** اگر وب‌سروری غیر از Apache دارید، دسترسیِ مستقیم به `data/` را خودتان ببندید.
- سقفِ حجمِ بارگذاری را `upload_max_filesize` و `post_max_size` در PHP تعیین می‌کند (هر فایل حداکثر ۲۵MB).
- بدونِ هیچ وابستگیِ بیرونی کار می‌کند (فونت/کتابخانه از اینترنت نمی‌آید).

## ساختار

| پرونده | کار |
|---|---|
| `index.php` | پوستهٔ صفحه |
| `api.php` | همهٔ عملیات (JSON)، ورود، CSRF، آپلود |
| `inc/db.php` | SQLite و ابزارهای مشترک |
| `inc/import.php` | ایمپورتِ فایلِ پروژه/گزارشِ هوش مصنوعی |
| `assets/engine.js` | ایندکسِ درخت، زمان‌بندی (مسیر بحرانی)، ساختنِ فایلِ خروجی |
| `assets/app.js`, `app.css`, `jalali.js` | رابط، تقویمِ جلالی |

## قرارداد فایلِ پروژه (`*.pm.json`)

`schema: "weby-projectmanager/1"`. کلیدها: `project`, `build_order` (فقط خواندنی)، `nodes`, `dependencies`, `milestones`,
`logs`, `files` (فقط نام)، `work_report`، و `_instructions_for_ai` (دستورالعملِ خودکار برای هوش مصنوعی).

ایمپورت (حالت «به‌روزرسانی»):

- گره با `id` موجود ← فقط کلیدهای حاضر عوض می‌شوند؛ `id` ناشناخته (مثلاً `"new-1"`) ← گرهٔ تازه (می‌تواند `parent`
  یا سرِ وابستگی باشد). پاک‌کردن فقط با `"deleted": true`.
- وابستگی‌ای که دور بسازد یا بینِ والد و فرزند باشد رد و در هشدارها گزارش می‌شود.
- `logs` بدونِ `id` اضافه می‌شوند (ایمپورتِ دوباره، ردیفِ قبلی را تکرار نمی‌کند).
- `work_report`: وضعیت/درصد را به‌روز می‌کند و گزارش را در تاریخچهٔ همان بخش می‌نویسد (`kind = ai_report`).
